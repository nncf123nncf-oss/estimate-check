# 見積チェック

見積もり項目を足すたびに、合計がその場で変わる計算道具です。

制作・修理・コンサル業の個人事業主が、現場や電話口で「これも足して」「数量を2つに」と言われるたびに
数量・単価・値引き・税を計算し直す——その手間をなくすために作りました。

## できること

- 見積もり項目（項目名・数量・単価）を追加する
- 数量を＋−ボタンで増減する／単価をその場で書き換える
- 項目ごとの金額と小計を自動で計算する
- 値引きを「金額」でも「％」でも指定する
- 消費税率を 10% / 8% / 0% から選ぶ
- 合計金額を常に画面上部に表示する
- 項目を削除する（確認あり）
- 顧客へそのまま送れる内訳のテキストを作り、1タップでコピーする
- 空欄・0・負数などの入力の誤りをその場で知らせる

## 計算のしかた

```
小計 − 値引き = 税抜き金額
税抜き金額 + 消費税 = 合計金額
```

端数処理:

- 数量・単価・値引き（金額指定）: 整数のみ受け付けるため、丸めは発生しません
- 値引き（％指定）: 四捨五入
- 消費税: 1円未満を切り捨て

## いまできないこと

- **同じ道具を2つのタブで同時に開かないでください。** あとから操作したほうの内容で上書きされ、
  もう一方で作っていた見積もりが消えます
- 入力の途中で誤った値（例: 単価に「1.5」）が残ったまま、欄を離れる・画面を切り替える・
  読み込み直すと、その入力は破棄されて**編集前の値に戻ります**。誤った金額のまま保存しないための動きです
- 数量は整数のみ、単価は1円単位のみです（「1.5時間」のような小数の数量は入力できません）
- 見積もりは1件だけ保存されます。複数の見積もりを並べて持つことはできません

## 使っている技術

React / TypeScript / CSS / Clipboard API / Vite

入力した内容はブラウザの中（localStorage）にだけ保存されます。外部に送信しません。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm run build   # docs/ に本番ビルドを出力
```
